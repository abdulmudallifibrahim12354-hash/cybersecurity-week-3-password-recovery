
# Cybersecurity Internship – Week 3

This repository documents my Week 3 practical cybersecurity activities focused on password recovery and password security testing in a controlled lab environment.

## Main Focus

This week's practical work focused on understanding how password-protected files can be analyzed and tested using password hashes, wordlists, and password recovery tools.

## Tools and Techniques Used

### John the Ripper
John the Ripper was used to perform password recovery testing against the extracted password hash.

### pdf2john
`pdf2john` was used to extract the password hash information from password-protected PDF files for testing with John the Ripper.

### Dictionary-Based Testing
A wordlist-based approach was used to test candidate passwords against the extracted hash.

### NetworkWalks Browser-Based Tools
NetworkWalks browser-based password security tools were also used as part of the practical exercise.

## Skills Practiced

- Password hash extraction
- Password recovery testing
- Dictionary-based password attacks
- Wordlist usage
- John the Ripper
- pdf2john
- Password-protected PDF analysis
- Practical password security assessment

## Learning Outcome

This practical exercise helped me understand the relationship between password-protected files, password hashes, wordlists, and password recovery tools.

It also demonstrated why strong and unique passwords are important for protecting sensitive files and accounts.
