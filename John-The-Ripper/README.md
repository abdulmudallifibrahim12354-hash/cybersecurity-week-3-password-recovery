# John the Ripper

This section documents my practical work with John the Ripper during Week 3.

## Activities

- Extracting password hash information from a password-protected PDF using `pdf2john`
- Preparing the extracted hash for password recovery testing
- Using John the Ripper with a wordlist
- Observing and analyzing the results of the password recovery process

## Purpose

The exercise was performed in a controlled lab environment to understand how password recovery tools work and why strong passwords are important.
